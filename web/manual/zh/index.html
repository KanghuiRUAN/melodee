SLOOP 是一款针对 M-VAVE FM-1 乐器设计的免费开源 (GPL-3.0) 固件，基于 Leo Kuroshita / Hügelton Instruments 的 Felucca 项目二次开发。简易手册请参阅 SLOOP.md；项目主页请参阅 README.md。

安装与更新

通过浏览器安装（推荐）：使用 Chrome 或 Edge 浏览器打开安装器网页，用 USB 数据线将 FM-1 直接连接电脑（请勿使用 Hub 集线器）。点击 INSTALL 并授权 MIDI 访问，等待提示 Done 即可。设备会自动重启并显示 SLOOP Logo。

在本地源码安装 (Windows)：双击运行 INSTALL-SLOOP.bat，脚本会自动编译固件并在浏览器打开 http://localhost:8766/webapp/installer/。安装完成前请勿关闭黑色的命令行窗口。运行 OPEN-EDITOR.bat 可直接打开网页编辑器。

更新固件：更新不会覆盖您的工程、预设、采样、鼓组和系统设置。安装程序会自动校验固件包 (SHA-256)，SLOOP 的刷机引导程序在写入前还会再次校验 (CRC)，若包损坏则拒绝写入，确保设备安全。

降级须知：若计划退回旧版固件（2.3 或更早版本），请务必先在 Web 编辑器中导出备份。2.3 版本无法读取 2.4 及以上版本的 FUN5 工程格式。

在任何界面下，转动 ALGORITHM 旋钮均可切换当前正在演奏、录制和编辑的轨道。屏幕与编辑器的色彩主题会随之切换。屏幕上的白色永远代表您当前操作的项；红色永远代表正在录音。

轻按 (Tap) 与按住 (Hold)

每个功能按键均拥有两种操作模式：

轻按 (Tap)：打开对应的参数页面（用于音色调制与详细设置）。再次轻按可切换至该按键的下一页。转动 SELECT 旋钮也可以双向翻页。按键会记住您上次停留的页面。

按住 (Hold)：进入对应的功能图层 (Layer)。按住按键时，16 个白键与 4 个旋钮将映射为快捷操作界面；按住超过 0.14 秒后，屏幕会显示由 16 个方块构成的 4x4 网格界面（对应琴键 1–4, 5–8, 9–12, 13–16）。松开按键后即刻恢复琴键演奏。

包含快捷图层的按键有：FX（实时特效）、EDIT（擦除）、ARP（连打）、SEQ（步进）、SEL（调性与和弦）、GLO（混音）以及 SAVE（曲目结构）。ENV 与 LFO 没有图层，仅用于打开设置页。

定位背光提示：在按住图层时（以及在鼓轨道下），琴键 1、5、9、13 会保持微亮。它们对应每排方块的第一个，便于盲操定位。高亮全亮的琴键代表当前处于激活状态。

图层锁定 (Layer Lock)：按住任意图层按键的同时轻按 HOME。松开按键后该图层将保持锁定打开状态（屏幕提示 LOCK，按键灯闪烁）。这样可以解放双手，一手按键一手转旋钮。轻按其他任意页面按键（如 HOME、当前按键、ENV 等）均可解锁。在锁定状态下，PLAY、REC 以及 OCT − / OCT+ 依然可以正常响应。

图层内的通用逻辑：在任何图层中，PLAY 均可随时控制播放/停止，SELECT 始终用于调节速度，ALGORITHM 与 PRESETS 旋钮处于保护状态（松开图层时参数不会意外跳变）。

60 秒快速上手（制作一段 Beat）

1. 将 ALGORITHM 旋钮转到轨道 4（橙色鼓轨道）。此时白键映射为 16 种鼓音色：F3 底鼓 (Kick)、G3 底鼓 2、A3 军鼓 (Snare)、B3 拍手 (Clap)、C4 踩镲 (Hat)、D4 开镲 (Open Hat)…… 转动 PRESETS 旋钮切换鼓组，推荐尝试 808 或 BOOMBAP。

2. 按一下 REC（屏幕显示 rec ready 进入录音准备）。随意击打琴键录制一段节奏，无需关注预备拍或节拍器 —按住 OCT − 击打可录入弱音 (Ghost Note)，按住 OCT+ 为重音 (Hard Hit)。

3. 在您小节结束后的第一个重拍“1”上再次按下 REC。Loop 自动闭合：系统会根据您演奏的时长自动计算 BPM 速度，并将音符自动对齐网格（量化），随后立即开始循环播放。

4. 播放过程中再次按下 REC 即可进行叠录 (Overdub)。按住 ARP 并在琴键上按住踩镲键 (C4)，即可实时录入 16 分音符的踩镲滚奏 (Ratchet)。

5. 将 ALGORITHM 切换到轨道 1（蓝色合成器，预设为 808 BOOM），按下 REC 录制一段 Bassline。

6. 按住 SEL 并在琴键上按下您这首歌的主调音符（例如 D 音）。切换到轨道 2，按住 SEL 并将 KNOB 1 旋转至 7TH：此时每一个白键都变成了该调内对应的七和弦，单指即可弹奏和声。

7. 按住 FX 并按住任意琴键（白键或黑键）触发 Punch-in 实时特效；在按住 FX 的同时转动 KNOB 2 加入 DUST 复古质感，转动 KNOB 3 调节 DUCK 侧链抽气效果。

8. 弹错了？按下 EDIT + OCT − 即可撤销 (Undo)。

键盘演奏模式

合成器轨道 (1–3)

琴键用于演奏当前选中的轨道。演奏的音符会同步通过 USB MIDI 输出（对应当前轨道的通道）。

OCT − / OCT+：调整八度范围 (−3 … +3)；双键同按立即重置为 0。当八度偏移时，OCT 灯会亮起提示。

琴键的实际响应取决于该轨道的 KEYS 设置与 CHORD 和弦模式（在 SEL 图层或 SEL 页面中配置）：

KEYS 设置 CHORD 模式 琴键响应逻辑
OFFOFF全半音阶模式（默认模式）
SNAPOFF按下的音符会自动向下修正（吸附）到当前设置的音阶上
WHITEOFF白键从 C4 开始映射当前音阶的音符（C4 = 当前音阶根音）；黑键不发声
任意开启 (On)白键演奏当前音阶的和弦，一键触发（C4 = Ⅰ级和弦）；黑键用于改变和弦属性（详情参见 CHORD+）

例外：当音色选用 GM KIT（属于 SAMPLE 采样引擎）时，最低音琴键固定为底鼓 (C2)，不受音阶设置影响。

鼓轨道 (4)

16 个白键分别对应 16 种鼓音色；黑键默认触发其左侧白键的音色（方便用双指交替打出极快的滚奏）。按住 OCT − 可以击打出弱音，按住 OCT+ 可以击打出重音。详情见鼓轨道详解。

力度与音量分级

FM-1 的硬件琴键不支持动态力度响应。在鼓轨道中，每次击打支持 4 种音量等级：GHOST ( 弱音)、SOFT (软击)、NORM ( 标准)、HARD ( 重击)。您可以在实时演奏时通过按住 OCT − / OCT+ 来指定，也可以后续在步进编辑器中修改。在合成器轨道中，步进可以设定重音 (Accent)标记（在 STEP 页面中的 FLAG 参数）。

录音与循环录制

SLOOP 支持实时叠加录音 (Overdub)。系统会自动补偿约 12 ms 的硬件发声延迟，使得录入的音符能够精准对齐到您耳朵听到的拍子上。合成器轨道在 VOICE 设为 POLY 时支持录入和弦（单步最多 4 个音符；若设为 MONO、LEGATO 或 UNISON，如大多数 Bass 和 Lead 音色，则一次仅响应并录入单音）；按住琴键不放会自动录入延音(Tie)。TRACKS 页面每个步进显示一个标记；STEP 页面会提示和弦包含的其他音符（如 +1, +2）。

外接 MIDI 键盘录音：按下 REC 时固定录制到当前选中的轨道。通道为 1、2、3 的 MIDI 键盘将始终固定演奏轨 1、2、3（2.6 版本后可通过 GLO → MIDI 设定通道），无论当前选中的是哪一轨；若想让 MIDI 键盘自动演奏和录制当前选中的轨道，请将键盘通道设置为 4（或 4–16）。2.6 版本起，若外接键盘演奏的轨道与当前录音轨道不一致，屏幕会提示 MIDI PLAYS TRACK n 予以提醒。

REC 按键功能逻辑

触发场景 REC 的响应 随后状态
正在播放中立即开启当前轨道的实时录音再次按下 REC 停止录音，Loop 继续循环播放
停止状态，工程内已有音符进入录音准备状态（rec ready，REC 灯闪烁）弹下第一个音符即刻启动 Loop 并作为第 1 步；按下 PLAY 亦可直接启动
停止状态，全新空白工程进入录音准备状态（rec ready·play freely）进入自由录音模式 (Free Take)；若 MODE 设为 tempo 则按设定节拍录制

在录音准备状态下再次按下 REC 可取消准备（REC OFF）。在 Song 模式下，REC 需等停止播放后方可响应（提示 STOP THE SONG FIRST），开启 REC 准备会自动切回 Loop 模式。

录音进行时，REC 灯保持常亮，当前轨道会显示红色的 rec 标识。在录音过程中转动 ALGORITHM 旋钮，录音焦点会自动平滑无缝地无停顿切换到下一个轨道。

自由录音模式 (Free Take)：速度随您而定

1. 在空白工程中，按下 REC，随后完全自由地弹奏一段乐句。屏幕会显示 free take、已录制秒数，以及当前推算的 Loop 信息（例如 2 bars·92 bpm）。

2. 在您小节结束后的第一个重拍“1”上按下 REC。SLOOP 会自动匹配最接近的 1、2 或 4 小节长度（若与预设速度相差在 3% 以内则锁定预设速度），将音符、时值与音量精准写入，并立即开始循环播放。其余 3 个轨道会自动对齐到该小节长度。

3. 在自由录音期间按下 PLAY 会直接放弃本次录制。若持续弹奏超过 24 秒未按 REC，录制会自动闭合结束。

节拍器与 Swing 摇摆感

PLAY 键指示灯在每个拍子上闪烁：构成视觉无音节拍器。

打开声音节拍器：进入 GLO → GLOBAL → CLICK 设置为 OFF（关闭）、REC（仅在轨道录音时响）或 ON（只要播放就响）。节拍器使用独立的清脆 Sound，小节首拍音高更高，即使鼓轨静音或开启了其他轨独奏也能清晰听到；音量大小受 GLO → DRUMS → LVL 控制。节拍器声音绝不会被录入 Sequence 中，预备拍期间始终开启节拍器。

Swing (摇摆感)范围为 0（完全平直）到 100（极强摇摆：偶数步进延迟播放，最大达到 75 / 25 的比例，类似于 MPC 75% Swing）：在 HOME 界面转动 KNOB 1 或进入 GLO → GLOBAL → SWING 可调整全局 Swing，在 SEQ + KNOB 3（或 SEQ → PATTERN → SWG）中可针对单轨叠加 Swing。三连音划分不受 Swing 影响。

录制内容细则

合成器轨道：录入音符（及和弦）与时值；按住不放录入延音 (Tie)；ARP 滚奏录入为连打 (Ratchet)；

CHORD+ 改变后的实际和弦音符。

鼓轨道：录入击打位置与音量等级；ARP 滚奏录入为连打 Ratchet（例如在 1/16 轨上打 1/32 滚奏会录入为单步 x2 连打）。

绝不被录入的内容：Punch-in 实时特效、节拍器 Click 声、以及在图层按键被按住时（琴键被挪作他用，如 FX、SEQ、GLO 时）弹奏的音符。

步进序列表：Steps、微调、参数锁定、Fill 条件

每个轨道最高支持 64 个步进，并拥有独立的长度 (Length) (1–64) 与时值划分 (Division)（从 1/32 到两小节）。不同长度的轨道会自动各自循环并保持相位对齐（多套复节拍 Polymeter）。合成器步进单步最多包含 4 个音符（和弦），并附带音量、连打、延音 /休止、重音与滑音标记；鼓步进可包含 16 种音色中的任意组合，每种音色拥有独立的音量与连打。

录入步进有三种方式：

1. 实时录音 — 按 REC 边听边弹（参见录音与循环录制）。

2. SEQ 图层 — 按住 SEQ，在白键上点亮步进（全轨通用；参见 SEQ — 步进编辑图层）。

3. STEP 设置页 (合成器轨) — 轻按 SEQ：通过琴键在光标所在位置写入步进，类似于经典的 Acid 步进输入逻辑：

Nudge ( 微调 / 微观时序)

SEQ + 步进键 + KNOB 4 可以将某个步进偏离标准网格，调节范围为 −32 到 +31（单位为 1/64 步进）：负值 = 提前（在前一步进的时值范围内提前触发），正值 = 推迟。该步进上的连打 (Ratchet) 会随之偏移；实时录音与 Swing 摇摆依然基于网格对齐。在鼓轨道上，微调作用于该步进上的所有鼓音色。被微调过的步进，其屏幕方块右上角会显示一个小圆点。

参数锁定 (Parameter Locks)

参数锁定允许您仅在某个特定步进上覆盖修改声音参数（类似 Elektron 独家的 Parameter Lock 机制）。

1. 在对应的参数页面转动您想要锁定的参数旋钮（例如 FX → DLY send，或 LFO → RATE）。该参数即被设为当前的目标锁定参数（在您未操作过任何旋钮前，默认目标为 ENV DEST → FLT）。

2. 按住 SEQ，同时按住目标步进键。

3. 转动 PRESETS 旋钮：转动第一格即可创建锁定（参数在默认值基础上偏离 1 格），继续转动可调整锁定值。

屏幕标题栏会显示锁定状态（如 lock dst 14；显示 lock flt --代表尚未建立锁定）。

4.（保持按住步进键）按下 ALGORITHM 可以循环切换并选择其他参数进行锁定。

当播放指针扫过下一个没有设置该参数锁定的步进时，声音会自动恢复为轨道的默认基准值（先前音符的尾音会平滑过渡）。在参数页面转动旋钮调整基础值不会破坏已建立的参数锁定。单个步进上可以叠加多个不同参数的锁定，每条轨道最多支持 24 个参数锁定。可被锁定的包括轨道的全部声音参数（以及 PATTERN 页面的 GATE）；

Arp 琶音、音阶 /和弦、STRUM/VLEAD、发音数模式、静音、LEN/DIV/SWG 以及全局设置页面无法被锁定（会提示 NOT LOCKABLE；若 24 个额度用尽则提示 NO LOCK LEFT）。包含参数锁定的步进同样会在方块右上角显示小圆点；通过 SEQ + 步进键 + OCT − 可以同步清除微调与参数锁定。撤销功能 (EDIT + OCT−) 仅作用于步进音符本身的增删，不会复原微调与锁定。

时值划分 (Divisions)

DIV (划分选项)：1/4, 1/8, 1/16 (默认值), 1/32, 8T, 16T (三连音), 1/2, 1BAR ( 单小节), 2BAR ( 两小节)。一条设定为 2BAR 划分的 64 步轨道，总时长可达 128 个小节：非常适合编排环境长音 (Drone)、长和弦走势或慢板曲目。

调性、音阶、和弦与 CHORD+

调性与音阶

SEL + 任意琴键即可设置全曲的主调 (Key)，同步作用于 3 个合成器轨道（例如屏幕显示 KEY D）。（也可在 SEL 页面中针对单轨单独设置 ROOT）。

KEYS (琴键映射)：OFF (全半音阶)、SNAP (自动吸附修正到音阶音符)、WHITE (白键从 C4 开始顺序映射音阶音符，黑键静音 )。

TRANSPOSE ( 移调)：针对单轨进行 ±24 半音范围的移调。

更换音色（通过 PRESETS 或用户预设）绝不会覆盖您已设定的调性、和弦模式、Sequence 内容或混音比例。

CHORD+：黑键修改和弦属性

在开启和弦模式的状态下，按住任意黑键的同时弹奏白键 — 或者在按住白键保持和弦响起的过程中按下黑键，和弦属性会在您的手指下实时发生变化：

黑键位置 和弦属性改变效果
F#大和弦↔小和弦互换
G#叠加 7 度音（转化为七和弦）
A#转化为 Sus4 挂四和弦
C#叠加 9 度音（转化为九和弦）

高低两个八度的黑键均可触发，且支持同时按住多个黑键进行组合。叠加的 7 度与 9 度音均严格遵循当前音阶：在 C 大调下，G4 默认触发 G 大三和弦 (Ⅴ 级)，按住 G# 会变成 G7，同时按住 F# + G# 则会变成 Gm7；在 C4 上，同时按住 F# + G# 会得到 C-E♭-G-B。您所弹奏并听到的改变会如实录入到 Sequence 中。

Song 模式：段落、链式播放与完整歌曲

一首完整的 Song 最多可包含 16 个步骤，由 A–D 4 个段落 (Sections)编排而成。每个段落完整保存 4 个轨道的全部状态（音色、Pattern、鼓套组），并独立占用 4 个工程槽位之一。

现场实时编排与录制

1. 制作一段 Loop（如主歌段落）。按下 SAVE + 琴键 5：提示 save A。修改节奏 /和声制作副歌段落，按下 SAVE + 琴键 6 保存至 B；同理将桥段保存至 C (琴键 7)，将 Outro 尾奏保存至 D (琴键 8)。覆盖已有数据的段落需要在 3 秒内再次敲击按键确认。

2. 现场手动切换段落：按住 SAVE + 琴键 1–4。播放中切换：新段落会在当前小节结束后无缝切入，所有轨道从第 1 步开始同步对齐播放。停止时切换：立即将该段落载入为当前编辑 Loop。

3. 快速链式播放 (Quick Chain)：保持按住 SAVE，依次快速敲击多个段落键 — 例如 A B B C，顺序任意，支持重复，最多 8 段 — 随后松开。第一个段落会在下一小节切入，随后每个段落会在播放完自身的 Pattern 长度（由最长的一轨决定）后自动切入下一段，循环往复。屏幕标题栏会显示 chain A B B C；正在播放的段落键保持常亮，下一个待播放的段落键闪烁框选。单按一次段落键、按 STOP 或在 Song 模式下按 PLAY 均可随时终止链式播放。

4. 实时录制 Song 结构：按下 SAVE + 琴键 14。从下一小节开始，您切换的所有段落以及每个段落播放的完整小节数都会被实时录入为 Song 数据。再次按下 SAVE + 琴键 14（或按 STOP）完成录制（提示 SONG PARTS 5）。停止播放后系统会自动保存 Song 数据。SONG REC 也会同步录下链式播放 (Chain) 的自动切换过程。

5. 回放整首歌曲：按下 SAVE + 琴键 13 将播放模式切至 song。在 Song 模式下按下 PLAY 会从头完整播放整首歌曲，并在结尾自动停止（停止后会自动恢复至您之前的 Working Loop 状态）。

补充说明：

全局页面 (Global)（DLY, REV/CHO, GLOBAL, MASTER, SYSTEM, DRUMS）无论当前选中哪条轨道，修改的均是全局参数。

SYNC、MIDI 与 IN 属于 FM-1 设备级设置，加载工程时不会被覆盖。

在鼓轨道下，有效的参数页包括 SLICER、PATTERN (SEQ)、SONG 界面与所有全局页面；鼓组、音量、混响与声相请在 DRUMS 鼓机界面调节，单轨滤波请使用 FX + KNOB 4。

FM6 引擎轨道会忽略 ENV 页面与 ENV DEST 设置（因为 FM6 的 6 个算子拥有各自独立的四段包络）。

ENV SYNC (ENV DEST → ESYNC ON，2.6)：ATK、DEC 与 REL 会切换为跟随 BPM 的节拍音符时值，范围从 0 到 1/64T … 1/4, 1/2 … 直至 4BAR（包含三连音与附点）；在 120 BPM 下，1/4 时值的 ATK 为半秒，在 60 BPM 下则为 1 秒。修改 BPM 速度时包络时长会自动按比例缩放。设为 OFF 时恢复为毫秒 (ms) 固定时长。

LFO 2 (2.6)：SYNC 可将 LFO 调制周期严格锁定至节拍音符时值（此时 RATE 忽略；设为 OFF 时恢复 Hz 速率控制）·TRIG 设为 NOTE 时每当弹奏新乐句会从 PHS 相位重置 LFO，设为 FREE 时保持自由运行·POL 设为 BI 时呈双极上下摆动，设为 UNI 时呈单极单向摆动（如仅向下压低音量的 Tremolo 或仅向上打开的 Wobble）。

FILTER (EDIT 页面，仅限 ANALOG 引擎，2.6)：ANALOG 引擎的滤波器可切换为低通 (LP)、带通 (BP)或高通 (HP)；CUT、RES 与 KTR 参数与 EDIT 2 页面完全同步。

在屏幕上，EDIT 1 与 EDIT 2 会直接显示各个引擎专属的页面名称：如 ANALOG OSC / FLT、DIGITAL OPS /MOD、PHASE PHS / LINE、LOFI CHIP / MOTN、SAMPLE SET / TONE、VOICE VOWL / TONE、TRIO OSC /TONE、WHEEL BARS / TONE、GRAIN GRAN / SPRY、FM6 OPS / PATCH、PHYS BODY / EXCT、NOISE SRC /MOVE。

上述页面中的所有声音参数均可在步进上进行参数锁定 (Parameter Lock)（参见参数锁定），Pattern、Arp、音阶调性与 VOICE 模式参数除外。

FM6 引擎与 DX7 音色文件

FM6 引擎底层采用 msfa（即 Dexed 的核心 FM 合成内核）：包含 6 个拥有独立四段包络的算子、键盘跟踪、力度响应、倍频比 /固定频率与解调；内置 32 种 FM 算法、反馈、LFO 及音高包络；每轨支持 6 个复音。上述 8 个 EDIT 参数是作用于音色之上的宏控制 (Macros)：轨道的 FLT 会联动调节 MLVL（因此 LFO → FLT 依然能产生明暗扫频效果），SHP 联动 FB 反馈，PIT 联动音高。

您可以在 Web 编辑器的 FM6 面板（Sound 页面中选中 FM6 轨）中编辑完整的音色细节：独立调整每一个算子、Send to track (发送至设备)、Store in bank (存入设备 Bank B1–B27)、Import SysEx (导入 SysEx 文件)（支持导入单音色或包含 32 个音色的预设包，互联网上数以万计的 DX7/Dexed 音色均可在 FM-1 上完美播放；也可直接将 .syx 文件拖入面板）以及 Export SysEx (导出 SysEx)。使用 Store cartridge in bank (2.5) 功能可以一次性将包含 32 个音色的完整预设包导入 FM-1：选中的音色（默认前 27 个）会按顺序一次性写入 B1, B2… 槽位中；

CH1–CH4：可设为 OFF 或 1–16 通道。轨道的通道决定了外部 MIDI 控制该轨的响应（音符、CC 控制器、延音踏板、弯音轮、Program Change 切音色），且该轨的琴键与 Sequence 也会从该通道输出。设为 OFF 代表该轨不接收也不发送任何 MIDI 信号。两个轨道绝不会强行共享同一个通道：若将某个通道分配给已被占用的轨道，原先占用该通道的轨道会自动递增切至下一个空闲通道，屏幕会弹窗提示（如 CH 3 = TRACK 3）。

切换通道会自动切断该通道上正在响起的尾音。CH4 与 GLO → DRUMS 中的设置完全同步。

IN：NOTES（接收音符、CC 控制器与 MIDI Clock 时钟：正常模式）·CLOCK（仅接收 MIDI Clock 及 START / CONTINUE / STOP 传输指令；忽略所有音符与 CC）·CH 1 … CH 16（仅接收指定的单通道信号，且始终作用于当前选中的轨道；CH1–CH4 与 OTHER 设置会被临时旁路，MIDI Clock 依然响应）。当 IN 设为非 NOTES 模式时打开 GLO → MIDI，屏幕会弹窗提示（如 IN CH 5: SEL TRK ONLY 或 IN = CLOCK: NO NOTES）。

OTHER：当收到的 MIDI 通道不属于 1–4 轨的任何一轨时的响应逻辑：SEL 代表自动演奏当前选中的轨道（例如将 MIDI 键盘通道设为 4，它就会跟随 ALGORITHM 自动切换控制焦点）·OFF 代表直接忽略（适合单根 MIDI 线连接多台设备时忽略其他设备的通道）。

OUT：KEYS 代表仅将您在硬件琴键上弹奏的音符输出·SEQ 代表将内置 Sequencer、琶音器与连打滚奏的音符同步输出。

BEND：设置弯音轮的响应范围，可调 1–12 个半音（默认 2）。

IN 与 OUT 设置同样呈现在 GLO → SYSTEM 页面中 SYNC 参数旁，与 2.6 版本前的布局保持兼容。

常见应用配置举例：MIDI 键盘设为通道 1 控制轨 1；若想通过通道 4 自动控制当前选中的轨道，请将 OTHER 设为 SEL。使用外接 Sequencer 编排：鼓轨设为 10，Bass 设为 2，Pad 设为 11，Lead 设为 8：设置 CH1 = 2, CH2= 11, CH3 = 8, CH4 = 10, OTHER = OFF。使用 KeyStep Pro 编排且其他通道控制外部硬件：设置 IN = CH n，该通道即可专注控制当前选中轨。

MIDI LEARN 自定义映射 (2.6)

您可以将控制器的任意物理旋钮映射至轨道的任意参数上（基于 Felucca 1.5）：

1. 按下 GLO + F#3（第一个黑键）：屏幕提示 LEARN: TURN A KNOB；顶部显示 LEARN 标识。

2. 转动 SLOOP 上您想要被控制的物理旋钮（当前轨的任意参数页，或 TRACKS 界面上的 LEVEL / PAN）：屏幕提示 T1 CUT: SEND A CC。

3. 转动 MIDI 控制器上的目标物理旋钮：屏幕提示 CC 21 = T1 CUT。您可以继续旋转其他旋钮进行批量学习映射。

4. 再次按下 GLO + F#3：提示 LEARN DONE，完成映射。

学习后的自定义 CC 会直接控制该轨道的对应参数，无论从哪个通道传入均可响应，且不再触发原有的标准 CC 映射（若某个 CC 之前已被占用，会自动解除原有映射；最多支持自定义 16 个 CC）。具备特定系统含义的 CC 无法被学习映射：如 Bank Select (0, 32)、Mod Wheel (1)、Data Entry (6, 38)、Expression (11)、Sustain (64)、96–101 以及 Channel Mode 指令 (120–127)。MIDI LEARN 的学习映射属于 FM-1 设备级系统设置，关机不丢失，不受工程切换影响，且会自动打包在 Web 编辑器的备份中；通过 HOME 菜单 → SYSTEM → MIDI LEARN CLEAR（按 OCT+ 确认）可一键清空所有学习映射。

USB 声卡功能

通过 USB 数据线连接时，FM-1 会被电脑/手机识别为名为 Felucca 的标准免驱 USB 音频输入设备：支持 44.1 或 48 kHz 采样率（由电脑 /手机/平板自动协商；2.5 版本起升级支持 48 kHz，完美兼容仅支持 48kHz 的手机与应用）、16-bit 立体声、符合 USB Audio Class 规范，无需安装任何驱动。在 DAW、Audacity 或手机采样 App 中（使用 USB-C 数据线或转接头）选择该输入源即可直接录音：录入的声音为总混音 Master 输出，与您在耳机里听到的完全一致（包含 DUST、DUCK 与 FILT 效果；若开启了 Click 节拍器与预备拍也会一并录入）。同一根 USB 数据线可同时传输 MIDI、连接 Web 编辑器与刷机更新。

FULL (满幅模式)：输出固定电平，相当于将 MASTER 转到底的音量（内置 Limiter 会确保绝不爆音剪切）；

自定义采样与鼓组制作

FM-1 硬件内置 4 个采样槽位（USR1–USR4），每个槽位容量约 7.4 秒（22 kHz 单声道规格）。单个槽位可被配置为以下两种用途之一：

旋律乐器，供合成器轨道调用：将引擎设为 SAMPLE，SET 选为 USR1 … USR4（或 GRAIN 粒子引擎的 SRC），或者鼓套组，供鼓轨道调用：将 KIT 选为 USR1 … USR4，或选择 USR3+4 组合槽位（跨两个槽位构成约 15 秒容量的大型鼓组）。

推荐的高效配置方案：USR1 和 USR2 作为旋律采样乐器，USR3+4 组合作为一个大型自定义鼓套组。所有采样槽位的内容均需在 Web 编辑器中进行灌录导入。

制作旋律乐器 (编辑器 → Samples 页面)

1. 选择目标槽位。页面会通过 4 个卡片直观呈现每个槽位的内容与已用容量；若本次导入会覆盖原有采样（或覆盖 USR3+4 鼓组的一半），页面会自动弹窗警告提示。

2. 生成乐器音色，提供两种快捷途径：

导入切音文件 (一文件一音符)：拖入最多 16 个 WAV 音频文件（采样率不限，单 /立体声均可）。每个文件会绑定到指定的音符上，中间未绑定的琴键会自动以最近的音符进行变速变调变阶重采样。音符会自动从文件名中提取（例如 KEYS_C4.wav 对应 C4 = 60）或在列表中手动指定；虚拟键盘会直观展示每个文件覆盖的琴键范围；点击 ▶ 可在线试听；容量仪表盘会实时计算已用时长。每个文件均支持单独调节 Gain 增益（0 到 −24 dB，2.6 新增）；点击 Match levels 可以自动平衡所有文件的响度（自动将过响的文件拉低，确保所有切音以满幅动态均匀输出），随后可凭听觉微调。

长采样切割 (CHOP)：打开或拖入一段完整的录音文件（WAV, MP3, AIFF…），将其精准切割为最多 16 个 Chop 切块，分别映射至各个琴键。

3. 发送并试听：为乐器命名，点击 Send to USRn，随后点击 Play this slot on track 1, 2 or 3：目标合成器轨道会自动切换为 SAMPLE 引擎并将 SET 设为该 USRn 槽位。

制作鼓套组 (编辑器 → Drum kit 页面)

1. 配置鼓音色。将 WAV 音频文件分别拖入 16 个鼓打击垫之中（KICK, KICK 2, SNARE, CLAP, HAT, OPEN HAT, PEDAL, RIM, SNARE 2, LOW TOM, HI TOM, CRASH, RIDE, SHAKER, CONGA, COWBELL），或点击 Choose files 批量导入：系统会自动根据文件名关键字（如 kick, bd, snare, hh, open, crash…；第二个 Kick 会自动分配至 KICK 2）智能分发至对应的打击垫。点击打击垫的波形可实时试听。每个打击垫均可独立调节 Pitch (音高 ±12 半音)、Gain (增益)与 Length (时长，剪裁尾部会自动施加平滑淡出）。点击 Match levels（2.6 新增，位于打击垫下方）可以根据人声听觉曲线自动平衡所有鼓垫的响度（低频能量自动折算，将过响的鼓垫降至与最弱鼓垫平齐），随后可凭听觉微调。

2. 选择目标槽位。可选择 USR3+4（大型鼓组，容量约 15 秒；编辑器会自动将 16 个音色智能打散平铺至两个槽位中），或选择单槽位 USR1–USR4（容量约 7.4 秒）。每个选项均会明确提示当前槽位的内容及覆盖后果。仪表盘会实时计算已用容量；若超长可手动缩短长音色或点击 Fit the slot 自动适应。

3. 发送至设备。为鼓组命名，点击 Send，随后点击 Use … on the drum track：系统会自动选中轨道 4 并将其 KIT 设为该鼓组（也可在 FM-1 鼓轨上转动 PRESETS 选择：USR3+4 位于鼓组列表的最末尾）。

点击 Save as ZIP 可将鼓组的 16 个 WAV 文件打包保存以便分享；点击 Open ZIP（或直接拖入 .zip 包）可一键加载已有鼓组包。

在 FM-1 上，您的自定义鼓套组与内置鼓组的使用体验完全一致：支持步进、音量分级、连打、Fill 条件、DRUMS 网格、琴键触发、MIDI 通道 10 控制（音符触发对应音色）、单轨滤波、切音器及 Mute 静音。闭合踩镲会自动切断开镲。未配置采样的空通道保持静音，未导入数据的空槽位亦同。

您可以通过安装器网页、编辑器直连链接，或者双击 OPEN-EDITOR.bat，在 Chrome 或 Edge 浏览器中打开 Web 编辑器。确保 FM-1 已通过 USB 数据线连接，点击 Connect 并授权 MIDI 访问。编辑器会与 FM-1 硬件保持完全双向实时同步：转动 FM-1 上的物理旋钮，编辑器的 UI 画面会同步跳动。UI 设计完美复刻了 FM-1 的硬件美学：黑底屏幕、4 轨代表色以及 FM-1 原汁原味的像素字体。点击语言切换按钮可自由切换中文 / 英文 / 日文。

离线单文件版 (2.6)：点击 Download the editor（位于 Connect 按钮下方，或在安装器页面），即可将整个编辑器下载保存为单文件 sloop-editor-2.6.html（每个 GitHub Release 发布页亦有提供）。双击该文件即可直接在 Chrome 或 Edge 中打开，无需连接互联网（Chrome 仅在首次打开时询问授权 MIDI 权限），功能与在线版完全一致。离线版的音色预设库（保存在浏览器本地）与在线版相互独立：您可以通过 Export / Import 导入导出，或通过全局备份文件在两者之间迁移数据。

作为 PWA 应用安装，支持 Android 手机 (2.6)：在连网状态下打开一次在线编辑器或安装器页面，随后点击 Install the app（位于 Connect 下方，或点击 Chrome 菜单 → 安装应用 / 添加到主屏幕）。之后 SLOOP 即可作为独立 App 运行，完全脱机离线使用，且内置的固件安装器链接同样支持离线刷机。它与在线版共享浏览器存储，因此会同步使用同一个音色预设库；当您再次连网打开时，App 会自动无感更新至最新版本。在 Android 手机上，请优先使用 PWA 应用形式：因为 Android 版 Chrome 安全策略限制在直接打开本地 HTML 文件时调用 Web MIDI 权限。

UI 布局：左侧边栏包含 3 个分组的页面导航 — Track (轨道功能) (Sound, Sequencer, Tracks, Song)、Sounds(音色采样) (Library, Samples, Drum kit, Drum synth)、Device (设备管理) (Projects, Settings) — 以及设备连接状态。顶部栏显示当前页面标题、状态提示文本，以及在 Track 页面下呈现的 4 个轨道标签卡（显示轨道号、音色名与引擎）：点击标签卡可直接切换焦点轨道。当焦点处于侧边栏时，使用键盘上下方向键可快速切换页面。

参数调节逻辑：每个参数项均呈现为可像旋钮一样上下拖拽的方块（按住 Shift 为微调），或滑动条：点击参数后可使用鼠标滚轮或方向键进行调整（按住 Shift 调整步幅为 10）；双击参数即可瞬间复位。

钢琴卷帘窗与 MIDI 文件导入导出 (Sequencer)

Piano roll 钢琴卷帘窗 (合成器轨)：从左至右为步进，从下至上为音高音符（点击 Octave up / down 可滚动八度视图）。选择音符写入长度（小节的 1/1 到 1/16，步幅受轨道的 DIV 约束），随后：

点击空白处：写入一个对应长度的音符。若点击已有和弦的第 1 步：可追加和弦音符（单步最多 4 音，和弦音符共享长度，与硬件逻辑一致）；

点击已有音符：直接删除该音符（删除和弦的最后一个音符会自动将该步变回 Rest 休止）；

拖拽音符右侧边缘：拉伸或缩短音符长度（自动生成 /消除 Tie 延音），最长可拉伸至下一个和弦步进前。

所有的修改均会实时无缝同步至 FM-1 硬件，网格视图也会同步更新。

Export MIDI 功能可将当前轨道的 Pattern 导出为标准的 MIDI 音频文件 (sloop-track1.mid …)：完整保留音符时值、长度、音量等级与 Accent 重音，且严格匹配曲目的 BPM；鼓轨道会自动导出为标准的 MIDI 通道 10 GM 鼓音符。

Import MIDI 功能可将外部 MIDI 文件导入读取至当前轨道，并根据轨道的 DIV 进行网格吸附。导入前会先弹窗预览：展示 MIDI 文件包含的轨道、音符数、步进数，以及导入过程中将发生的自动修正提示：不在网格上的音符会自动平移吸附至最近的步进、单步超过 4 个音符时会自动保留音量最大的前 4 音、被后续音符截断的长音、超过 64 步的截断部分。点击 Import 会覆盖当前轨道的 Pattern（若勾选对应选项，会自动将轨道长度设为 MIDI 的实际长度）；点击 Cancel 放弃导入保留原样。在鼓轨道下，标准 GM 鼓音符会自动精准映射至对应的鼓音色通道（36 底鼓、38 军鼓、42 踩镲…），MIDI 力度值会自动精细转化为 GHOST 至 HARD 4 个音量等级。

与 FM-1 硬件逻辑一致，编辑器仅在 Song 停止播放时才允许将预设、FM6 Bank 与备份文件写入 Flash 闪存（若在播放中，编辑器会弹窗提示您先停止播放）。您可以在没有连接 FM-1 硬件的情况下直接体验编辑器：只需在编辑器网址末尾加上 ?mock=1 即可开启虚拟仿真模式。详细的数据通信协议文档参阅 web/EDITOR_PROTOCOL.md。

备份、救砖恢复、降级与故障排查

备份与还原

打开编辑器 → Projects 页面 → 点击 Backup：

Save a backup ( 导出全局备份)：一键将 FM-1 硬件上的所有数据完整打包导出为一个独立的 JSON 文件(SLOOP-backup- 日期.json )：包含您当前正在制作的音乐、工程槽位 1–4（即 Song 段落 A–D）、用户预设音色库 1–32、FM6 音色 Bank B1–B27、自定义采样槽位 USR1–USR4、自定义合成鼓组 SYN1–SYN4、MIDI LEARN 学习映射，以及所有的 FM-1 系统级硬件设置。建议在更新固件或出厂重置前导出备份。

Restore a backup ( 还原备份)：选择一个备份文件并恢复至 FM-1 硬件上。还原前编辑器会弹窗复选框，允许您自定义勾选需要恢复的具体数据板块（例如仅恢复工程，或仅恢复用户预设）。还原会将硬件上的对应数据完全覆盖：如有疑问，请在还原前先导出当前数据的备份。请在 Song 停止状态下执行还原。

硬件救砖模式 (USB Rescue Mode)

若更新固件中途意外断电、数据线拔出，导致 FM-1 开机黑屏、卡在 Logo 界面或按键无响应：

1. 拔下 USB 数据线，关机。

2. 按住 OCT − 键不放，同时插上 USB 数据线（或开启电源）。

3. 屏幕会显示 SLOOP USB RESCUE 救砖提示字样。

4. 在电脑上使用 Chrome 或 Edge 浏览器打开安装器网页，点击 INSTALL 重新刷入固件。刷机完成后设备即可恢复正常。

无论硬件处于何种卡死状态，救砖引导程序 (Bootloader) 均保存在只读保护区内，绝不会被损坏，您可以随时通过此方法救砖。

固件更新模式 (UBOOT)

若浏览器端安装器无法自动切入刷机模式：在停止播放状态下，同时按住 OCT − + OCT+ 5 秒。屏幕会出现 2 秒倒计时；倒计时结束前松开可随时取消。倒计时结束后 FM-1 会先将当前工作工程自动保存，随后强制重启进入 UBOOT 刷机模式，此时安装器网页即可正常识别并刷入固件。

降级至旧版固件 (如 2.3 或更早)

1. 在 Web 编辑器中导出当前硬件数据的全局备份。

2. 在安装器页面选择旧版固件文件（.bin 或 .hex）刷入设备。

3. 旧版固件 (2.3) 无法读取 2.4 及以上版本的工程格式 (FUN5)：若降级后工程显示为空，此属于正常现象。若日后重新升级回 2.6，再次导入您的备份文件即可完整还原所有工程。
